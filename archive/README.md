# Archived source material

These files preserve the project inputs that existed before the expanded
Smithsonian/NMAH data pipeline was introduced on 2026-10-06.

- `2026-10-06-small-curated-version/` is a copy of the 19-object editorial and
  generated dataset, plus the two scripts that built it. The same version is
  also recoverable from Git commit `4809b5c`.
- `original-si-fetch/` preserves the original 25,807-result Smithsonian API
  fetch and the browser scripts used to produce and analyze it. The original
  data contains 5,387 records whose source is the National Museum of American
  History.

The archived files are reference material. New scripts must not overwrite
them.
