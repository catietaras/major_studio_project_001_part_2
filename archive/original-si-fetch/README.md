# Original Smithsonian fetch

This is a preserved copy of the earlier `00-fetch-si-js` experiment referenced
by the project.

- `george-washington-all-smithsonian-legacy.json` contains 25,807 search
  results for `george washington`.
- 5,387 of those rows have `source` equal to
  `National Museum of American History`.
- The legacy `location` property describes geographic subject metadata. It is
  not a floor or gallery location inside the museum.

These files are intentionally not used directly by the visitor-facing site.
